3. 快速开始

3.1 文本模型调用示例

curl http://192.168.0.151/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <apikey>" \
  -d '{
    "model": "deepseek-r1-distill-qwen-32b",
    "messages": [
      {"role": "user", "content": "请用三句话解释 Kubernetes 调度。"}
    ],
    "max_tokens": 512
  }'

3.2 Python 示例

import requests

url = "http://192.168.0.151/v1/chat/completions"
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer <apikey>",
}
payload = {
    "model": "deepseek-r1-distill-qwen-32b",
    "messages": [
        {"role": "user", "content": "请用三句话解释 Kubernetes 调度。"}
    ],
    "max_tokens": 512,
}

resp = requests.post(url, headers=headers, json=payload, timeout=120)
resp.raise_for_status()
print(resp.json())

4. 通用接口说明

如果服务采用 OpenAI-compatible API，建议统一使用 /v1/chat/completions。

字段 类型 必填 说明
model string 是 模型名称
messages array 是 对话消息
temperature number 否 采样温度
max_tokens integer 否 最大生成长度
stream boolean 否 是否流式返回

常见 messages 格式：

[
  {"role": "system", "content": "你是一个有帮助的助手。"},
  {"role": "user", "content": "请解释 GPU 调度。"}
]

5. 模型使用说明

5.1 qwen3-vl-32b-instruct

项目 说明
能力 文本 + 图片理解
适用场景 图片问答、截图分析、视觉内容总结、多模态推理
不建议场景 高并发批量图片处理、大文件长期占用、未压测的低延迟场景
GPU 资源 2×H100
限制 图片大小、上下文长度、并发限制待补充

图文请求示例：

curl http://192.168.0.151/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <apikey>" \
  -d '{
    "model": "qwen3-vl-32b-instruct",
    "messages": [
      {
        "role": "user",
        "content": [
          {"type": "text", "text": "请描述这张图片的主要内容。"},
          {"type": "image_url", "image_url": {"url": "http://<image-url>"}}
        ]
      }
    ],
    "max_tokens": 512
  }'
图片输入格式以实际服务实现为准。如使用 base64、本地文件上传或对象存储地址，请在此处补充。

6. 支持与反馈

使用中遇到问题，或有新模型、新能力、配额提升、压测支持等需求，可联系星脑团队反馈和提需求。

反馈问题时请尽量提供以下信息：

  • 模型名称
  • 请求时间
  • 请求 ID（如果有）
  • 输入规模，例如 token 数、图片大小
  • 错误信息或异常现象
  • 是否使用流式返回
  • 复现方式或最小请求示例
